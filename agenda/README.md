# Base de agenda para demostración

Demo reutilizable de una agenda para negocios de uñas y estética.

Incluye creación y edición de citas, horarios disponibles, resumen financiero, mensajes de WhatsApp y respaldo local. Los datos se guardan solamente en el navegador y no se sincronizan con servicios externos.

> Los nombres, direcciones, enlaces, datos bancarios y políticas visibles son marcadores que deben personalizarse para cada cliente.
